# Foundations: decision-centered combat design

## Layers
Base Skill → Numerical Enhancements (separate track) → 3 equipped Behavioral Augments → one Evolution Branch with Ranks 1–3 → optional accepted Mutation. Species trait, passives, skills, global weather and local terrain overlay these via static modifiers or event-driven reactions.

**Evolution** = changes core verb and combat role. **Augment** = changes *how you play* that role. **Mutation** = special authored recipe that substitutes a new loop. **Synergy** = conditional interaction which need not override base mechanics. **Enhancement** = scaling only.

## Player-control test
Because attacks often auto-fire, each behavioral modifier must influence at least one real decision: where to move, when to stand still, who to approach/avoid, how to group enemies, how to draft supporting skills, how to spend/retain a resource, how to set up and cash out terrain/status. If no observable decision changes, mark it as a numerical enhancement.

## Standard skill DNA
Name, thematic fantasy, combat role, initial targeting policy, delivery pattern, time/cost, hits, duration, status ownership, geometry, hard caps, element/form/effect tags, mechanical affordances, weakest scenario, visual/audio readability, evolution eligibility.

## Three-rank branch rhythm
1. **Transform**: change delivery, attack location, target policy or role.
2. **Engine**: add propagation, stored charges, repeated setup, and meaningful movement reward.
3. **Payoff**: spend accumulated resources or trigger a bounded culmination, frequently resetting part of setup.

## Three types of effects
1. Config-time numeric modifiers: damage, rate, width, duration etc.
2. Stateful runtime behaviors: projectile travel, plant growth, target links, charge storage.
3. Reactive synergies: event-triggered cross-system effects with explicit prerequisites.

## Semantic promises
Augment promises stay consistent across skill transformations, but their animation need not. Example **Inheritance** preserves unused duration/charge: Leech Seed transfers infection lifetime; Razor Leaf converts unused bounce budget into a new leaf; Poison Powder transfers remaining duration; Solar Beam retargets unused energy following a kill. Different implementation; one coherent promise.

## Design review
Explain in plain language: 'Before this upgrade, the player tried to _____. After it, the player tries to _____ because _____.' If the two blanks are substantially identical, change the concept.
