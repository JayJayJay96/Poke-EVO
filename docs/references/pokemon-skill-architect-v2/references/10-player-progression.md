# Player-facing progression and upgrade economy

## Draft UX
Main level-up offers skills, ordinary enhancements, passives and behavioral augments with clear 3-slot ownership. Separate milestone evolution choice displays branch role, rank 1 mechanics, projected augment conversions and weakness. Synergies activate automatically, with readable on-screen cue and a discovery journal. Mutations appear as optional dedicated offers when their recipe is met; accepting shows what is lost and gained.

## Recommended MVP assumptions (tunable)
4 active move slots; 4 passive slots; up to 3 behavioral augments PER move; 1 rank per behavioral augment at first; 2 shared evolution paths per move; up to 1 family signature path on selected skills; 3 ranks per branch; three options per level-up draft. Do not require all three augment slots to be filled before evolution; existing augments may be changed by limited respec if a branch invalidates one.

## Bulbasaur family milestones (proposed test pacing)
Start with Vine Whip. New moves at early levels. Mastery unlocks augment slots 1/2/3. Eligible skill evolution offers appear after mastery threshold, with pity/guaranteed appearance after a small number of missed drafts. Bulbasaur evolves into Ivysaur at level 16 and Venusaur at 32 as a familiar optional baseline; run pacing can adjust it. Chosen skill evolutions persist through form evolution; form-specific additions unlock upon evolving rather than deleting prior build choices.

## Fair access
- At most one mutation per skill at a time unless intentionally designed otherwise.
- Rare discovery should not be compulsory for basic viability.
- Weather randomness should not be mandatory for a recipe without player-controlled way to provide it.
- Choice previews must state slot ownership, replacement behavior and compatibility before confirmation.
- Display trigger conditions and cooldowns in a discovery journal; hiding exact recipes can be a deliberate optional discovery mode, not a requirement to consult external documentation.
