# Bulbasaur family — 35-minute sample reference run

Illustrative trajectory, not a guaranteed route. Base Pokémon starts with Vine Whip and can learn Leech Seed, Razor Leaf, Poison Powder, Synthesis, Solar Beam. Four skill slots, four passives.

| Time | Level target | Events | Meaningful decision |
|---|---:|---|---|
| 0:00 | 1 | Vine Whip equipped | Base attack and positioning |
| 3:00 | ~5 | Augment ticket 1 | First behavioral customization after mastery slot unlock |
| 6:00 | ~9 | Augment ticket 2 | Choose another skill or specialize |
| 9:00 | ~13 | Augment ticket 3 | Prepare Leech Seed build |
| 10:00 | ~14 | Evolution ticket 1 | Choose LS Living Garden or other eligible route |
| ~11:00 | 16 | Ivysaur evolution | Trait matures, builds persist |
| 13:00 | ~17 | Augment ticket 4 | Add Momentum/Anchor to garden |
| 15:00 | ~19 | Evolution ticket 2 | Rank up or diversify |
| 17:00 | ~21 | Augment ticket 5 | Seek Volatility via bounded focus weighting |
| 21:00 | ~26 | Augment ticket 6 + evolution ticket 3 | Batched reward UI; commit sequentially |
| 26:00 | ~31 | Augment ticket 7 | Build specialization |
| ~27:00 | 32 | Venusaur evolution | Full Bloom species mechanics |
| 27:00 | ~32 | Evolution ticket 4 | Rank up focused path |
| 31:00 | ~36 | Augment ticket 8 | Further specialization |
| 32:00 | ~37 | Evolution ticket 5 | Final major skill evolution |
| 35:00 | ~40 | Boss | Test horde/boss trade-offs |

Mastery/evolution/XP are distinct. Eligibility timing may shift. If no compatible unlocked augment slot at an opportunity, pending ticket queue handles it; never claim all eight are automatically equipped. Optional mutation offered after authored recipe: e.g. Living Garden + Momentum + Volatility → Wandering Blight, with acceptance and explicit loss of permanent garden coverage.
